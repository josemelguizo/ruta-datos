# Ruta de Ingeniería de Datos

Mi camino para aprender ingeniería de datos desde cero: 46 semanas, unas 12 horas por semana.

## Etapas

1. **Fundamentos:** SQL, Python, Git y terminal.
2. **Pensar como ingeniero de datos:** modelado, ETL y Docker.
3. **Herramientas del mercado:** nube, dbt, Airflow y Spark.
4. **Portafolio y empleo:** certificación, proyectos y entrevistas.

## Proyectos

Diez proyectos prácticos, cada uno en su propio repositorio. El 1 es una solución de referencia; del 2 al 9 son retos con pruebas que se ponen en verde a medida que los resuelvo; el 10 es el proyecto final de portafolio.
